Studentske radionice – zimski semestar

Osnove HTML-a i CSS-a

Radionica za potpune početnike. Pravimo prvu web stranicu od nule i učimo kako je stilizirati pomoću CSS-a.

Trajanje: 2 dana po 3 sata, cijena: 20 KM

Git i GitHub (preporučeno)

Učimo osnovne Git komande, rad s granama i postavljanje koda na GitHub. Preporučujemo je svima jer se zadaci na vježbama obavezno predaju preko GitHub repozitorija, pa je ovo znanje potrebno od prve sedmice.

Trajanje: 1 dan, 4 sata, cijena: 15 KM

Uvod u JavaScript

Radionica za one koji već poznaju HTML i CSS. Učimo varijable, funkcije i kako dodati interaktivnost na web stranicu.

Trajanje: 3 dana po 3 sata, cijena: 30 KM
